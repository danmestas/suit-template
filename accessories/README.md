# Accessories

Small, named, repeatable add-ons applied via `suit ... --accessory <name>` (repeatable).

Each accessory is a directory: `accessories/<name>/accessory.md` with frontmatter declaring an `include:` block listing skills/rules/hooks/agents/commands to layer in.

Use `/new-accessory` (Claude Code slash command) to scaffold a new one.

See suit's [ADR-0010](https://github.com/danmestas/suit/blob/main/docs/adr/0010-rename-and-three-tier-composition.md) for full resolution semantics.
